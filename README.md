Picverse is a website that can be use to find artwork and also can be a social media, that combine a few social media into one

1. Home Page 
   For the Home Page, it use the design of Pinterest that can be use to find images/post from trending hashtag, featured artwork, or explore that redirect to gallery

2. Gallery Page
   Gallery is a page where, user gonna find a lot artwork/post in one page that can be scroll down

3. Submit Page
   Submit Page is where the user gonna submit their artwork to the public

4. Community Page
   As the name said, this is a community page which is for people to see other artwork and give them a rating such as likes, commend, share, or maybe save the artwork. They can also follow the Artist.

5. About Page
   A page about picverse, contact, support, etc.
